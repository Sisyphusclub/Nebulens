# 图片详情弹窗比例布局

## 需求：桌面动态尺寸

桌面图片详情弹窗必须使用固定视口高度和动态内容宽度：根容器宽度适配内容但不得超过视口宽度的 92%，高度为视口高度的 80% 且不得超过 720px。右侧详情面板固定为 340px，媒体区占用剩余宽度。

### Scenario: 三种常见比例动态伸缩

- GIVEN 用户打开一张 1:1、3:2 或 16:9 的图片详情
- WHEN 弹窗在桌面视口中显示
- THEN 根容器高度为 `80vh` 且最大高度为 `720px`
- AND 根容器宽度随图片比例和媒体区内容伸缩且最大宽度为 `92vw`
- AND 右侧面板宽度保持 340px，不因图片比例收缩

## 需求：图片高度撑满且不裁切

左侧媒体区必须占满弹窗高度并居中显示图片；图片高度优先撑满可用媒体区，宽度按原始比例自适应，最大宽度受 `92vw - 360px` 约束，并使用 `object-contain` 保证完整显示。

### Scenario: 横图和方图无上下大黑边

- GIVEN 用户打开一张 1:1、3:2 或 16:9 的图片详情
- WHEN 图片加载完成
- THEN 左侧媒体区高度为弹窗内容高度并使用居中 flex 布局
- AND 图片使用高度撑满、宽度自适应和 `object-contain`
- AND 图片完整可见，媒体区上下不出现由固定比例容器造成的大块空黑

## 需求：详情内容和操作区稳定

右侧面板必须保持固定宽度和完整高度；提示词与参数区域独立滚动，底部操作按钮区域不可被中间内容挤出视口。

### Scenario: 长提示词不截断操作按钮

- GIVEN 图片详情包含超长提示词或参数内容
- WHEN 用户查看详情弹窗
- THEN 中间内容区域可以独立纵向滚动
- AND 底部操作按钮完整可见并保持在面板底部

## 需求：移动端兼容

移动端继续使用现有全屏纵向弹窗布局，媒体区和详情面板按纵向排列，不要求沿用桌面动态宽度。

### Scenario: 小视口纵向布局

- GIVEN 用户在宽度不超过 860px 的视口打开图片详情
- WHEN 弹窗显示
- THEN 弹窗使用全屏高度
- AND 图片媒体区位于详情面板上方，详情内容和操作区仍按现有移动端方式可用
