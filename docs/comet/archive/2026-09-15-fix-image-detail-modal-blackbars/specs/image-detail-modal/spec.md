# 图片详情弹窗布局规格

## 场景

### Scenario: 桌面端图片完整显示

- GIVEN 图片详情弹窗在桌面视口打开
- WHEN 图片为 16:9、2:3、1:1 或其他比例
- THEN Modal 高度为 `85vh`，并受 `620px` 至 `760px` 限制、宽度受 `90vw` 和 `max-w-5xl` 限制
- AND 左侧媒体区高度填满、带 `p-8` 均匀内边距，图片使用 `object-contain` 完整显示

### Scenario: 详情内容与操作区不截断

- GIVEN 提示词和参数内容超过右侧可视高度
- WHEN 用户查看详情
- THEN 中间内容区域独立纵向滚动
- AND 右侧面板固定 `340px` 宽度
- AND 底部操作按钮组不收缩、保持底部并完整可见

### Scenario: 窄屏详情布局

- GIVEN 视口宽度不超过移动端断点
- WHEN 用户打开图片详情
- THEN 继续使用纵向媒体区和详情面板布局
- AND 图片不超出媒体区，详情内容可滚动

## 实现约束

- 保留现有操作回调、可见性状态和删除状态。
- 不为图片设置固定比例容器，避免横竖图被额外裁切。
